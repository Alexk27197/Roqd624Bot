# RoadWatch — בוט התראות על עבודות בכבישים 🚛

פרויקט התחלתי, ללא תשלום ל־AI וללא שרת פועל 24/7: GitHub Actions מפעיל פעם ביום את הבדיקה ושולח הודעת Telegram. **הבוט לא מותקן או פועל מעצמו אחרי הורדת הקבצים.**

## מה הוא עושה

- שולח ב־**17:30 לפי שעון ישראל** (התאמה אוטומטית לשעון קיץ).
- בודק שלושה מקורות פומביים: כביש 6, לוח אירועים נתיבי איילון וחוצה ישראל.
- מתייחס לנסיעה **מקריית אתא לעוטף עזה, בכיוון דרום**, ומדגיש סגירה מתוכננת באקה–ניצני עוז.
- מחזיר קישורים למקורות; **לעולם לא קובע שכביש פתוח רק משום שלא נמצאה חסימה**.
- לא עוקב אחרי תאונות, עומסי תנועה, אירועי משטרה, משקלים/גובה/מידות, חסימות מיידיות, או אחרי כל עבודה של נתיבי ישראל. תוצאות הן אינדיקציה ולא מידע מלא/חי.

## התקנה (מחשב)

1. בטלגרם פתח את [@BotFather](https://t.me/BotFather), לחץ Start ושלח `/newbot`. תן שם ומשתמש לבוט ושמור **בסוד** את ה־API token שקיבלת.
2. פתח את הבוט החדש שלך בטלגרם ושלח לו `/start`.
3. התקן Python 3.12 ומעלה. פתח טרמינל בתיקיית הפרויקט והריץ `pip install -r requirements.txt`.
4. הגדר את הטוקן כמשתנה סביבה בשם `TELEGRAM_BOT_TOKEN` במחשב שלך; **אל תדביק אותו כאן או בקוד ולא לקובץ בגיטהאב**. הרץ `python chat_id.py` וקבל את מזהה הצ'אט הפרטי (מספר).
5. פתח מאגר **private** חדש ב־GitHub והעלה אליו את תיקיית הפרויקט, כולל `.github/workflows/daily.yml`.
6. במאגר, עבור ל־Settings → Secrets and variables → Actions → New repository secret והוסף:
   - `TELEGRAM_BOT_TOKEN` = הטוקן מ־BotFather
   - `TELEGRAM_CHAT_ID` = מזהה הצ'אט שקיבלת משלב 4
7. עבור ל־Actions → RoadWatch daily roadworks alert → Run workflow לבדיקה ידנית. אם הצליח, תקבל הודעת Telegram. ההתראה היומית תישלח בהתאם ללוח הזמנים (GitHub עשויה לעכב מעט הרצות מתוזמנות).

**בדיקה על מחשב, בלי Telegram:** `python bot.py --dry-run`.

## התאמות

- שעת התראה: ערוך את שורת `cron` ב־`.github/workflows/daily.yml` (כרגע 17:30).
- מקורות: מילון `SOURCES` בראש `bot.py`.
- היגיון ההתראות: `build_report()` ו־`highway6_closure()`.

## מגבלות חשובות

זו **גרסת MVP**. HTML של אתרי המקור יכול להשתנות, אתר יכול לחסום בקשות אוטומטיות, או שפרסום יכול להיות חסר/מאוחר; דוח חלקי אמור להופיע עם אזהרה, אך הבוט עדיין עלול לפספס חסימה. כרגע הזיהוי של כביש 6 הוא ספציפי לקטע באקה–ניצני עוז — אין כיסוי מאומת לכל המחלפים. לא מתאים כתחליף למרכזי הבקרה, שילוט, הנחיות משטרה ולמערכת ניווט המאושרת למשאית.
